# Prueba2

Este proyecto es un juego de ajedrez implementado en HTML5 con JavaScript. Permite jugar una partida completa de ajedrez directamente en el navegador, con las siguientes características:

- Tablero interactivo de 8x8 casillas
- Movimientos válidos para todas las piezas (peón, torre, caballo, alfil, reina y rey)
- Sistema de turnos entre blancas y negras
- Detección de movimientos legales y capturas
- Botón para reiniciar la partida
- Interfaz gráfica con estilos CSS integrados
